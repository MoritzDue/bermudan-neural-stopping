# Results

The figures in [headline/](headline/) are the main results discussed in the repository [README](../README.md).

- `fig_neural_minus_lsm.png` — neural minus LSM across training budgets.
- `fig_primal_dual_bounds.png` — primal–dual estimates for the selected policies.
- `H2.csv` and `H3.csv` — the data used by `make_figures.py` to regenerate these figures.

The [supporting/](supporting/) directory contains the complete committed summary and per-run records: `summary.json`, `summary_main.csv`, `runs.csv`, `paired.csv`, `dates.csv` and `units.jsonl`. They are retained for inspection, not required for reading the main findings.

The datasets were moved without changing their contents. The frozen study and original checksum manifests remain at the [`study-v1` tag](https://github.com/MoritzDue/bermudan-neural-stopping/tree/study-v1).
